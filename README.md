# 📱 Amazon Smartphones Data Scraping & Price Prediction

A Data Science project where I collected smartphone data from Amazon using **Web Scraping**, cleaned and structured the raw data, and built a **Linear Regression model** for smartphone price prediction.

## 🔹 Project Workflow

**Web Scraping → Data Cleaning → Data Organization → Feature Extraction → Machine Learning**

### 🛠️ Tools & Technologies

- Python
- Pandas & NumPy
- BeautifulSoup
- Requests
- Regular Expressions (Regex)
- Scikit-learn
- Claude
- Antigravity

### 📊 Data Processing

The raw data contained inconsistent product descriptions, especially in **Arabic**, which made extracting features challenging.

I used Regex and several preprocessing steps to extract and standardize:

- Brand
- Model
- Storage
- RAM
- Color
- Camera
- Price

Due to the complexity of organizing and cleaning the data, I also used **AI-assisted development tools**, mainly **Claude and Antigravity**, to help identify different data patterns, improve the preprocessing logic, and handle various edge cases.

After cleaning and structuring the data, I used the final dataset to train a **Linear Regression model** for smartphone price prediction.

### 💡 Key Learning

This project gave me practical experience in working with **real-world messy data**, from collecting it from scratch to preparing it for Machine Learning.

It also showed me how **AI tools can support the development process** when dealing with complex data-cleaning and preprocessing challenges.

> **Good Machine Learning starts with good data.**
